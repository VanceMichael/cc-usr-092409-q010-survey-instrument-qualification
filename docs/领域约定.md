# 领域约定

原始采集包不可覆盖；构件对应关系随基线版本发布；隔离数据只有在摘要、序号和坐标信息完整后才能参与仲裁。

## 仪器资格与借用链

- 设备以序列号登记，记录组件组合、校准证书、适用精度与维修状态；设备、证书、租约、组合均带单调版本号。
- 借用申请绑定班组、工作区、时间窗（半开区间 `[starts_at, ends_at)`，边界相接不算重叠）与用途；出借由保管人确认，归还由领用人确认。
- 同一设备的 `requested`/`lent` 租约时间窗不得相交，由数据库触发器在写入路径上原子拒绝；`returned`/`rejected`/`cancelled` 不再占窗。
- 观测导入即冻结设备、证书、租约、组合的版本快照与规则轨迹，此后永不改写；重评结果只写入 `current_trace`。
- 合格观测进入候选解（`candidate`）；证书过期/撤销、维修锁定、越区、班组不符、组件不匹配、精度不足、租约缺失或逾期的观测进入待复核（`review`）；采集包不完整的进入隔离（`quarantined`）。任何观测记录都不删除。
- 证书撤销可追溯：撤销后该证书对历史观测同样失效；维修锁定按区间 `[opened_at, closed_at)` 判定，迟到结论在结案时生效。
- 证书撤销或维修结论迟到只重评未签署进基线的观测；已签署基线保留原资格快照，按（基线, 来源, 引用, 观测）追加风险，风险可确认。
- 离线交接按设备流水号归位；封签号全局唯一，同一封签的并发确认只有第一个成功。
- 逾期归还、证书到期与复核任务持久化在 `due_tasks`，同一引用只有一个活动任务；停服恢复时先重置搁浅认领、补齐缺失任务，再执行到期任务。
- 资格规则轨迹（`rule_trace`）与证据快照（`qualification_snapshot`）是解释一次观测为何采用、降级或隔离的唯一依据。
